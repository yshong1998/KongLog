# KongLog 프론트엔드 세션

이 폴더에서 실행된 Claude는 프론트엔드 담당이다. 공통 규칙은 루트 `CLAUDE.md`를 따르고, 여기에는 이 세션에만 해당하는 것을 적는다.

## 작업 순서

1. 깃허브에서 열린 이슈를 확인한다. 영역이 `frontend`인 이슈만 맡고, 본문의 할 일과 끝나는 기준을 읽는다.
2. 프론트엔드 작업을 진행한다.

## 담당 범위

- `frontend/`만 고친다. `backend/`와 `infra/`는 고치지 않는다.
- 백엔드는 모른다고 가정한다. 백엔드 코드를 읽어 API를 추측하지 않는다. API 주소와 응답 모양은 기획 문서와 `cowork/` 문서에 적힌 것만 사실로 본다.

## 백엔드와 주고받기

- 구현 중 백엔드에 요청할 것이 생기면 작업을 멈추고, 요청 문서를 만든 뒤 사용자에게 알린다. 임시 데이터나 추측으로 채워 계속하지 않는다.
- 문서 위치는 저장소 루트의 `cowork/issue_<이슈번호>/`다. 번호는 작업 중인 깃허브 이슈 번호와 같게 쓴다.
- 프론트가 백엔드에 보내는 요청은 `front_req_<순번>.md`, 백엔드가 프론트에 보내는 요청은 `back_req_<순번>.md`다. 순번은 `001`부터 올린다.
- 요청 문서에는 필요한 것, 필요한 이유, 쓰는 화면, 바라는 모양을 적는다.
- 작업을 시작할 때 `cowork/`에서 새 `back_req_*.md`와, 보낸 `front_req_*.md`의 완료 표시를 확인한다.
- 백엔드의 요청을 끝내면 그 `back_req` 문서 맨 위에 완료했다고 적는다. 그 밖의 내용은 고치지 않는다.

## 코드 규칙

아래 경로는 이 폴더(`frontend/`) 기준이다.

- **Next.js 16은 이전 버전과 다르다.** 기억에 의존하지 말고 `node_modules/next/dist/docs/`의 문서를 먼저 읽는다 (`AGENTS.md` 참고).
- 캐시 컴포넌트가 켜져 있다. 요청마다 새로 읽어야 하는 데이터는 `<Suspense>` 안의 컴포넌트에서 읽고, 캐시해도 되는 데이터는 `'use cache'`와 `cacheLife`를 쓴다.
- 서버 컴포넌트가 기본이다. `'use client'`는 상태나 이벤트가 필요한 컴포넌트에만 붙인다.
- 백엔드 호출은 `src/lib/api.ts`를 거친다.
- 타입 검사는 반드시 `npm run typecheck`로 한다. `tsc`만 돌리면 Next.js가 만드는 타입이 없어 실패한다.
- 올리기 전에 `npm run lint && npm run typecheck && npm test && npm run build`를 돌린다.

## 디자인 시스템

값은 `src/app/globals.css`에만 있다. 새 값이 필요하면 먼저 물어본다.

- 색: `bg-surface`, `text-ink-muted`처럼 정해진 이름만 쓴다. 색 코드를 직접 쓰지 않는다.
- 글자: `text-h1`, `text-h2`, `text-h3`, `text-body`, `text-small`, `text-code`. 블로그 이름만 `font-display text-wordmark`.
- 간격: 1, 2, 4, 6, 10, 16 여섯 단계만 쓴다.
- 모서리: 누르는 작은 것(버튼, 태그)은 `rounded-pill`, 내용을 담는 것(카드, 입력창, 코드 블록)은 `rounded-md`.
- 카드는 `bg-surface`에 `border-line` 테두리. 그림자는 쓰지 않는다.
- `bean`(연두)은 면에만 쓰고 글자색으로 쓰지 않는다. 초록 글자는 `link`.
- 기본 버튼(`bg-bean`)은 한 화면에 하나만 둔다.
- 누를 수 있는 요소의 높이는 44px 이상(`min-h-11`).

## 문구와 접근성

- 화면 문구는 "~해요"체로 짧게 쓴다. 이모지와 느낌표는 쓰지 않는다. 예: "아직 글이 없어요", "다시 시도"
- 실제 `<button>`, `<a>`, `<label>`을 쓴다. `div`에 클릭 이벤트를 달지 않는다.
- 아이콘만 있는 버튼에는 `aria-label`을 붙인다.
- 상태를 색만으로 구분하지 않는다. 문구나 모양 변화를 함께 준다.
