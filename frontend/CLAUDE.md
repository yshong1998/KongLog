# KongLog 프론트엔드 세션

이 폴더에서 실행된 Claude는 프론트엔드 담당이다. 공통 규칙은 루트 `CLAUDE.md`를 따르고, 여기에는 이 세션에만 해당하는 것을 적는다.

## 작업 순서

1. 깃허브에서 열린 이슈를 확인한다. 영역이 `frontend`인 이슈만 맡고, 본문의 할 일과 끝나는 기준을 읽는다.
2. 프론트엔드 작업을 진행한다.

## 담당 범위

- `frontend/`만 고친다. `backend/`와 `infra/`는 고치지 않는다.
- 백엔드는 모른다고 가정한다. 백엔드 코드를 읽어 API를 추측하지 않는다. API 주소와 응답 모양은 기획 문서와 `cowork/` 문서에 적힌 것만 사실로 본다.

## 백엔드와 주고받기

- 구현 중 백엔드에 요청할 것이 생기면 작업을 멈추고, 요청 문서를 만든 뒤 사용자에게 알린다. 임시 데이터나 추측으로 채워 계속하지 않는다.
- 문서 위치는 저장소 루트의 `cowork/issue_<이슈번호>/`다. 번호는 작업 중인 깃허브 이슈 번호와 같게 쓴다.
- 프론트가 백엔드에 보내는 요청은 `front_req_<순번>.md`, 백엔드가 프론트에 보내는 요청은 `back_req_<순번>.md`다. 순번은 `001`부터 올린다.
- 요청 문서에는 필요한 것, 필요한 이유, 쓰는 화면, 바라는 모양을 적는다.
- 작업을 시작할 때 `cowork/`에서 새 `back_req_*.md`와, 보낸 `front_req_*.md`의 완료 표시를 확인한다.
- 백엔드의 요청을 끝내면 그 `back_req` 문서 맨 위에 완료했다고 적는다. 그 밖의 내용은 고치지 않는다.
