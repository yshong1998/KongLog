안녕하세요, 웹 서비스를 만드는 주니어 개발자 Kong이에요. 화면에서 데이터베이스까지 한 기능을 처음부터 끝까지 만들어 보는 걸 좋아해요.

## 하는 일

- Spring Boot로 API 서버를 만들고, PostgreSQL에 데이터를 담아요.
- Next.js로 화면을 만들고, 서버에서 그리는 방식과 캐시를 공부하고 있어요.
- Docker로 내 컴퓨터와 서버의 실행 환경을 맞춰요.
- 이 블로그도 직접 만들고 있어요. 만드는 과정에서 만난 문제가 그대로 글이 돼요.
