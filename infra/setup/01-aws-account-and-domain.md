# 1. AWS 계정과 도메인

2단계(배포)를 시작하며 준비한 AWS 계정과 도메인의 기록입니다. 가입, 결제, 콘솔 설정은 모두 사람이 직접 했고, 여기에는 한 순서와 정한 값을 적습니다.

계정 번호, 비밀번호, 키 같은 비밀 값은 적지 않습니다.

## 정한 값

| 항목 | 값 |
| --- | --- |
| AWS 가입일 | 2026-11-25 |
| AWS 플랜 | 무료 플랜 |
| 무료 플랜이 끝나는 때 | 2027-05-25 무렵(가입 후 6개월)과 크레딧을 다 쓴 날 중 빠른 쪽 |
| 2단계 인증 | 아직 켜지 않음 (2026-11-25 기준) |
| 예산 알림 | 월 20달러 |
| 도메인 | konglog.my |
| 도메인을 산 곳 | 가비아 |
| 도메인을 산 날과 기간 | 2026-11-25, 1년 |
| 도메인 요금 | 첫 해 4,950원(부가세 포함), 갱신은 연 60,000원 |

## 잊으면 안 되는 날짜

| 언제까지 | 할 일 | 하지 않으면 |
| --- | --- | --- |
| 2027-05-25 전 | AWS를 유료 플랜으로 바꾸기 | 무료 플랜이 끝나면 계정이 닫혀 서버를 쓸 수 없습니다 |
| 2027-11-25 전 | 도메인을 갱신하거나 다른 도메인으로 바꾸기 | 도메인이 만료되어 블로그 주소가 열리지 않습니다 |

정확한 날짜는 AWS 결제 콘솔과 가비아의 도메인 관리 화면에서 확인합니다.

## AWS 가입

가입할 때 무료 플랜과 유료 플랜 중 하나를 고릅니다.

| | 무료 플랜 | 유료 플랜 |
| --- | --- | --- |
| 요금 청구 | 청구되지 않습니다 | 크레딧을 넘는 사용량은 청구됩니다 |
| 끝나는 때 | 6개월이 지나거나 크레딧을 다 쓰면 계정이 닫힙니다 | 닫히지 않습니다 |
| 쓸 수 있는 서비스 | 일부만 쓸 수 있습니다 | 모두 쓸 수 있습니다 |

- 가입하면 크레딧 100달러를 받습니다. 콘솔에 안내된 활동을 마치면 100달러까지 더 받습니다.
- 무료 플랜을 골랐습니다. 예상하지 못한 요금이 청구되지 않기 때문입니다.
- 블로그를 계속 운영하려면 무료 플랜이 끝나기 전에 유료 플랜으로 바꿔야 합니다.

### 무료 플랜에서 Lightsail을 쓸 수 있는지

2026-11-25에 Lightsail 콘솔에서 확인한 내용입니다.

- 무료 플랜 계정으로 Lightsail 서버를 만들 수 있었습니다.
- 지역은 시드니만 고를 수 있었습니다. 화면에 나온 안내 문구는 적어 두지 못했고, 같은 내용을 AWS 문서에서는 찾지 못했습니다.
- 월 12달러 플랜에 "첫 90일 무료" 같은 표시는 없었습니다. 첫 달부터 요금이 크레딧에서 빠진다고 보고 계산합니다.
- 크레딧이 Lightsail 요금에 실제로 적용되는지는 확인하지 못했습니다. 첫 청구서가 나오면 결제 콘솔의 "크레딧"과 "청구서"에서 확인합니다.

## 2단계 인증

로그인할 때 비밀번호 말고 휴대폰 앱의 코드를 한 번 더 확인하는 설정입니다. 아직 켜지 않았습니다. 켤 때는 아래 순서로 합니다.

1. AWS 콘솔 오른쪽 위의 계정 이름을 누르고 "보안 자격 증명"으로 갑니다.
2. "멀티 팩터 인증(MFA)"에서 "MFA 디바이스 할당"을 누릅니다.
3. "인증 관리자 앱"을 고릅니다.
4. 휴대폰의 인증 앱으로 QR을 찍고, 연속으로 나온 코드 두 개를 넣습니다.

## 예산 알림

요금이 정한 금액에 가까워지면 메일로 알려 주는 설정입니다. 예상하지 못한 과금을 가장 일찍 알 수 있는 방법이라 가입한 날에 걸었습니다.

1. 콘솔 홈의 "Explore AWS"에서 "Set up a cost budget using AWS Budgets"를 누릅니다. AWS 문서에는 이 경로로 만들면 크레딧 20달러를 더 받는다고 적혀 있습니다.
2. "Use a template"에서 "Monthly cost budget"을 고릅니다.
3. 금액과 알림받을 메일 주소를 넣고 만듭니다.

금액은 월 20달러로 정했습니다.

- 예상 요금은 월 13달러쯤입니다. Lightsail 12달러에 부가세 10%를 더한 13.2달러와 S3 백업 몇 센트입니다.
- 이 템플릿은 예산의 85%(17달러)에서 처음 알립니다. 평소에는 울리지 않고, 울리면 예상 밖의 과금입니다.

확인하지 못한 것이 두 가지 있습니다.

- 크레딧 20달러를 실제로 받았는지
- 요금이 크레딧으로 지워지는 동안에도 알림이 울리는지

## 도메인

konglog.my를 가비아에서 샀습니다.

- 이슈에는 사기 전에 등록 업체별 연 요금을 비교하기로 적혀 있었지만, 비교하지 않고 샀습니다.
- 첫 해 요금(4,950원)과 갱신 요금(연 60,000원)의 차이가 큽니다.
- 그래서 1년 뒤에는 갱신하지 않고, 이름 `konglog`는 그대로 두고 `.me` 같은 다른 도메인으로 바꿀 계획입니다.

도메인을 바꾸면 도메인에 묶인 설정을 함께 바꿔야 합니다. 기획 문서에서 도메인이 필요하다고 적힌 곳은 HTTPS, 소셜 로그인 등록, 메일 발송입니다. 3단계에서 검색엔진에 등록한 주소도 여기에 들어갑니다.
